# 1. CORE PRODUCT CONCEPT

A user takes a photo of their head/face.

The platform uses the image to create a personalized visual representation / 3D avatar.

The user can then customize glasses directly on their face:

* frame shape
* frame size
* frame thickness
* frame color
* material
* lens type
* style

Once the user creates a design they like, they select an optical center.

The platform then searches the catalog/inventory of THAT SPECIFIC OPTICAL CENTER and finds the closest available real glasses to the user's design.

The platform should NOT pretend to manufacture a completely custom pair of glasses.

The user's design is a TARGET.

The optical catalog provides the REAL products.

The platform's job is to find the closest match.
